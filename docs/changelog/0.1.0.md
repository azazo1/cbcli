# cbcli v0.1.0

Date: 2026-11-14

系统剪贴板的文件复制粘贴工具集首次发布.

## Highlights

- `pfcopy` 把文件放进系统剪贴板, `pfpaste` 把剪贴板里的文件或图片取到目标目录.
- 两个命令都能用 `--version` 查看当前构建的版本号.

## Features

- CLI: `pfcopy` 接受一个或多个文件路径, 也可以从标准输入逐行读取路径; 任一输入路径不存在时报错并返回非零退出码.
- CLI: `pfpaste` 默认把剪贴板中的文件复制到当前目录, 用 `-C` 指定目标目录, `-m` 改为移动, `-w` 允许覆盖已存在的目标文件, `-n` 只打印将要写入的路径而不落盘.
- CLI: `pfpaste` 支持粘贴目录, `--move` 对目录同样有效.
- CLI: 剪贴板里是图片而不是文件时, `pfpaste` 把图片保存为当前目录下的 `clipboard-<时间戳>.png`; 这种场合指定 `--move` 会报错.
